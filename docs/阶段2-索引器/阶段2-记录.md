## 5. 路上遇到的

- tree-sitter-wasms 包的语法 wasm 与 web-tree-sitter 0.27 不兼容（动态链接元数据不匹配）。换用 @vscode/tree-sitter-wasm，它把运行时和语法打在一起。
- web-tree-sitter 0.25 起 `namedChildren` 元素类型是 `Node | null`，所有遍历都要过滤。
- 该包是 UMD，ESM 的命名导入拿不到，用 `createRequire` 取。
- Windows 下 Node 的 `fs.watch` 递归可用（为阶段 5 验证过）。
